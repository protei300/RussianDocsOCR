# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для текущей мажорной линии (`2.x`).
Пользуйтесь актуальной версией — старые не обновляются.

## Как сообщить об уязвимости

Пожалуйста, **не** публикуйте уязвимости через обычные issue или PR.

Предпочтительный канал — приватный отчёт через GitHub:
**вкладка Security → Report a vulnerability** (Private vulnerability reporting)
в репозитории.

Если это недоступно — напишите мейнтейнеру на email из списка авторов в
[README](README.md#об-авторах-проекта) с пометкой «security».

В отчёте по возможности укажите:

- версию библиотеки и Python, ОС;
- затронутый компонент (пайплайн, конкретный модуль, скрипт, зависимость);
- шаги воспроизведения и потенциальное влияние;
- при наличии — PoC или патч.

## Чего ожидать

- Подтверждение получения — в течение нескольких рабочих дней.
- Оценку и обсуждение исправления; при необходимости — согласованное раскрытие
  после выпуска патча.

## Область

Библиотека распространяется вместе с ML-моделями и обрабатывает изображения
документов. Помимо уязвимостей в коде и зависимостях, сообщайте и о проблемах,
специфичных для ML (например, вредоносный вход, приводящий к аварийному
завершению или чрезмерному потреблению ресурсов).

Обратите внимание: загрузка моделей и данных из **недоверенных** источников —
зона ответственности пользователя. Формат хранения центроидов классификатора
намеренно переведён на `.npz` (без pickle), чтобы исключить выполнение
произвольного кода при загрузке штатных артефактов.
