# Поля штампов для дообучения OCR

В ветке `dev` доступны общий детектор полей печатных/рукописных штампов
YOLO11s-OBB и OCR Дмитрия v3. Веса выпускаются отдельно от кода как `models-v12`.
Детектор имеет пять классов: `date`, `addr_line`, `house`, `korp`, `flat`.
Другие штампы, например о браке, не являются его целевым входом.

## Нарезка

Связь поля со штампом сохраняется на обоих этапах. Ответ
`POST /api/v1/recognize/registration` содержит `stamps[]`: у каждого штампа
есть `index`, его `quad` и собственный список `boxes[]`. У поля есть `id`
вида `1.0` (штамп 1, поле 0), `label`, `text` и `quad`. Эти координаты
указывают на исходную присланную фотографию, а не на уменьшенную картинку
или локальные пиксели вырезанного штампа.

Команда ниже принимает уже вырезанные выпрямленные штампы. В её выгрузке
есть список `stamps`, у каждого поля — явный `stamp_id` и отдельный `id`.
`quad` здесь задан на входном штампе. Сам лоскут записывается в `crop`,
поэтому для текстовой разметки не нужно самостоятельно пересчитывать координаты.

После установки зависимостей скачайте модели:

```bash
python scripts/fetch_models.py
python scripts/crop_stamp_fields.py stamps --output fields_for_review
```

`stamps` — папка с отдельными выпрямленными штампами. Можно указать один файл.
Команда создаёт новую папку с `crops/*.png` и `annotations.json`. Исходные штампы
в неё не копируются, данные никуда не отправляются. Уже существующую папку
команда не перезаписывает, чтобы сохранить внесённые ответы.

Запас вокруг рамки по умолчанию — 0,3 высоты вдоль строки и 0,15 поперёк.
Он помогает сохранить крайние штрихи; соседние строки могут попасть в запас,
поэтому каждый лоскут нужно проверить. Параметры меняются через
`--pad-x` и `--pad-y`. Узкие числа сохраняют направление текста штампа.

Для подсказок OCR добавьте `--ocr`. Подсказка попадёт в `ocr_suggestion`,
отдельно от вашего эталона. По умолчанию подсказок нет.

## Текстовый эталон

В `annotations.json` у каждого поля есть класс, путь к лоскуту, координаты,
хеш исходного штампа и место для ответа:

```json
{
  "class": "addr_line",
  "crop": "crops/example_addr_line.png",
  "text": "УЛ. ПРИМЕРНАЯ",
  "reviewed": true,
  "unreadable": false
}
```

Вписывайте только текст выбранного поля, как он виден на изображении:
сохраняйте цифры, сокращения, пробелы и знаки препинания. Большие и маленькие
буквы при оценке не различаем. Не дописывайте ответ по смыслу или по соседнему
штампу. Если прочесть уверенно нельзя, оставьте `text: null`, поставьте
`unreadable: true` и `reviewed: true`.

Проверяйте, что рамка не срезала начало/конец текста и поле размечено верным
классом. Ошибочный лоскут отметьте комментарием `comment`, не выдавайте его
за правильный пример. При передаче нужны отдельные лоскуты и JSON; целые
страницы настоящих документов в репозиторий и публичные обращения не присылайте.
Канал передачи лоскутов согласуется с сопровождающим проекта.

`stamp_id` и хеш исходного штампа связывают его поля. При подготовке обучения
все лоскуты одного источника должны попасть в одну часть набора. Если несколько
штампов или снимков относятся к одной странице, задайте им одинаковый
обезличенный `source_group` в списке `stamps`: одного хеша штампа для такой
группировки недостаточно. Часть проверенных
примеров оставляется для независимой оценки, включая исходно правильные
ответы OCR. Нельзя учить модель на всём наборе и затем на нём же доказывать
улучшение.

Эта команда помогает собрать материал. Прежние оценки OCR на небольшой
проверочной выборке не гарантируют качество на присланных пользователями штампах.
